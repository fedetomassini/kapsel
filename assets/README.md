# Assets

- `logo.png`: local Kapsel brand image used by the app and optional executable icon generation.
- `fonts`: local icon font and accompanying asset files.

JetBrains Mono is preferred if already installed and is not bundled. Font loading has no network
dependency. Repository screenshots are under `.github/assets` and are packaged to preserve the root
README's relative image link.

Record new asset sources/licenses alongside the asset, preserve
the applicable notices and verify release inclusion. Do not replace binary assets during an unrelated
documentation or code change.
