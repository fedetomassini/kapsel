# Code of Conduct

Kapsel welcomes contributors with different backgrounds and levels of experience. Project spaces
include issues, pull requests, reviews, and other discussions hosted by the project.

## Expectations

- Be respectful, constructive, and specific. Discuss behavior and code without attacking people.
- Assume good intent, accept corrections, and explain technical disagreement with evidence.
- Make space for newcomers and respect people's time and privacy.
- Do not engage in harassment, discrimination, threats, sexualized conduct, personal attacks,
  repeated disruption, or sharing another person's private information without consent.

## Reporting and Enforcement

Contact the maintainer through the contact information on
[their GitHub profile](https://github.com/fedetomassini) for sensitive reports. If no private channel
is available, ask for one in an issue without publishing personal details. For ordinary moderation
requests, flag the relevant discussion to the maintainer.

The maintainer will review context and may request a correction, remove content, close or lock a
discussion, or restrict participation for serious or repeated violations. Enforcement should be
proportionate and protect reporter privacy. Maintainer conduct is subject to the same expectations;
GitHub's platform reporting tools remain available for platform-policy violations.
